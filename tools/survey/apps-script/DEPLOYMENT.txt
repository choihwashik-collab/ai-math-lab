AI MATH LAB 설문 전용 Apps Script 배포

기존 다른 앱의 프로젝트나 배포 주소를 수정하지 마세요.
같은 Google 계정에서 새 설문 전용 프로젝트를 만듭니다.

1. https://script.google.com/home 에서 새 프로젝트를 만듭니다.
2. Code.gs 파일을 이 폴더의 Code.gs 내용으로 교체합니다.
3. HTML 파일을 추가하고 이름을 Index로 지정한 뒤 Index.html 내용을 붙여넣습니다.
4. 프로젝트 설정에서 appsscript.json 표시를 켜고 이 폴더의 manifest 내용으로 교체합니다.
5. 함수 선택에서 setupSurveyBackend를 선택해 한 번 실행하고 권한을 승인합니다.
   이 프로젝트는 새 설문 응답 시트를 만들고 정리용 시간 트리거를 설치합니다.
   실행 로그에서 '설문 만들기 암호'와 응답 시트 주소를 확인합니다.
   암호는 공개 저장소나 참여자에게 공유하지 않습니다.
   응답 시트와 프로젝트는 비공개로 유지합니다.
6. 배포 > 새 배포 > 웹 앱을 선택합니다.
   실행 사용자: 나
   액세스 권한: 모든 사용자 (Google 로그인 없이 참여 가능)
   기관 계정에서 이 옵션이 없으면 관리자 정책을 확인하거나 개인 계정을 사용합니다.
7. /exec로 끝나는 웹 앱 URL을 복사합니다. /dev 테스트 URL은 참여자에게 공유하지 않습니다.
8. 웹 앱 URL을 tools/survey/config.js의 appUrl에 넣고 GitHub에 푸시합니다.
   기존 GitHub 설문 주소는 Apps Script 설문 화면으로 이동합니다.

운영 확인
- 웹 앱에서 설문 만들기 암호를 입력하고 방을 만듭니다.
- 교사용 관리 링크를 따로 보관합니다. 이 링크는 응답 조회·종료·삭제 권한을 가집니다.
- 참여 링크나 QR에는 교사용 토큰을 넣지 않습니다.
- 다른 휴대폰이나 시크릿 창에서 QR 링크를 열고 별명으로 응답합니다.
- 교사 화면에서 응답이 모이는지 확인합니다 (약 7초마다 갱신).
- 질문 추가 시 참여자 화면은 약 15초마다 확인하며 기존 입력은 유지합니다.
- 종료한 방은 제출을 차단합니다. 24시간 후 조회를 차단하고 시간 트리거가 응답을 정리합니다.
- 정리 대상은 이 설문 시트의 데이터 행입니다. Google의 백업·버전 기록 삭제까지 보장하지 않습니다.
- 최대 30개 질문, 방당 500명으로 입력 크기를 제한합니다.
  이 수치는 지원 성능 보장이 아니며 Apps Script 동시 실행·일일 사용량 제한이 적용됩니다.

기존 설문
기존 앱은 localStorage에 저장했으므로 이미 만든 QR은 다른 기기에서 동작하지 않습니다.
연결 후 새 설문방과 새 QR을 만드세요. 기존 localStorage 데이터는 이 변경에서 삭제하지 않습니다.

코드 수정 후
node tools/survey/apps-script/build.mjs 로 Index.html을 다시 생성합니다.
Apps Script의 Code.gs / Index.html을 업데이트한 뒤 배포 관리에서 새 버전으로 업데이트합니다.
기존 앱의 배포는 그대로 둡니다.
